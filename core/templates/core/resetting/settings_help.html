Choices are the option lists behind dropdown/select fields used across the app — each one is a named category (e.g. a dataset) holding a set of keys, and each key holds a list of values. Here's how to manage them.

  1. 1
    Open a category

    From Application Settings, click a key (e.g. status, type) to see every value currently in that list.

  2. 2
    Add a value

    Click Add, type the new value, and submit. It's appended to the list and immediately available anywhere that field is used.

  3. 3
    Edit a value

    Click the value itself to open it, change the text, and submit — it's replaced in place, so anything already using the old value keeps pointing at the same list position.

Good to know

No delete here
This legacy Choices system only supports adding and editing values, not removing them. If you need to remove an option entirely, rename it to something clearly unused instead.
